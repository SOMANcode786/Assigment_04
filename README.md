Welcome to my **Assignment 04** repository! This repository includes a series of Python projects I completed as part of my learning journey in the **Learn Modern AI with Python** course.

## 📂 Projects Overview

Below are the projects included in this repository, each showcasing different aspects of programming in Python:

### 🔹 P1: **Mad Libs Game**
- **Description:** A word replacement game that generates funny stories using user input.
- **Key Concepts:** String operations, user input, and randomization.

### 🔹 P2: **Guess the Number (Computer)**
- **Description:** The computer guesses a number you have in mind within a range.
- **Key Concepts:** Random number generation, loops, and user input.

### 🔹 P3: **Guess the Number (User)**
- **Description:** The user attempts to guess a number the computer has generated.
- **Key Concepts:** Conditional statements, loops, and random number generation.

### 🔹 P4: **Rock, Paper, Scissors**
- **Description:** A classic game of rock, paper, and scissors with the computer.
- **Key Concepts:** Conditional statements, random choices, and loops.

### 🔹 P5: **Hangman Game**
- **Description:** A word guessing game where you guess letters to complete a word.
- **Key Concepts:** String manipulation, loops, and conditionals.

### 🔹 P6: **Countdown Timer**
- **Description:** A timer application where users input the time, and it counts down to zero.
- **Key Concepts:** Time manipulation, loops, and user input handling.

### 🔹 P7: **Password Generator**
- **Description:** Generates secure random passwords for users.
- **Key Concepts:** String operations, randomization, and security.

### 🔹 P8: **BMI Calculator**
- **Description:** A simple application to calculate Body Mass Index based on user weight and height.
- **Key Concepts:** Mathematical operations, user input, and conditionals.
